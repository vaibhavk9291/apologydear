# 💌 A Little Note For You... 🥺

A cute, romantic-but-subtle interactive apology website and digital letter.

## ✨ Features

- **💌 Interactive Envelope Opening**: 3D envelope with animated wax heart seal and heart burst reveal.
- **🧸 Interactive Plush Teddy Bear**: Blushes and reacts with cute thoughts when you hover or approach.
- **🏃‍♂️ Cursor-Aware Dodging "No" Button**:
  - Real-time pointer proximity detection.
  - Smooth spring dodging physics so clicking "No" is hilariously impossible.
  - Playful changing dialogues & particle trails.
- **💖 Celebration & Confetti**:
  - Full-screen celebration with custom pastel heart confetti and happy bear dancing animation.
- **🤫 Secret Letter Reveal**:
  - Progressive typing effect for an intimate, heartfelt confession letter.
  - Gently pulsing glowing heart.
  - Virtual hug button & re-read experience.
- **🎵 Music Box Synthesizer**:
  - Built-in soothing Web Audio API music box lullaby (no external audio files required, never autoplays).
  - Floating music toggle and gentle sound effects.
- **🌸 Dreamy Visuals**:
  - Soft pastel palette (pink, lavender, cream, baby blue).
  - Glassmorphic frosted cards, floating clouds, stars, and sparkles.
  - Desktop heart cursor trail.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
